# Sales_Invoice_Tracking_System

Small and medium retail businesses—including electronics shops, stationery stores, hardware shops, and general stores—may rely on manual processes for recording sales and generating invoices. Sales are often recorded in a day-book and bills are issued using printed invoice books. Monthly reports may require manually summing daily transactions.
The Sales & Invoice Tracking System replaces this workflow with a lightweight web application that can run on a shop computer and, when configured on a local network, be accessed from other devices on the same Wi-Fi network. It centralizes customer data, product data, orders, invoices, and reports in a searchable database and calculates totals automatically.
